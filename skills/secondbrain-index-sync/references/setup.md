# 처음 설정

이 문서는 `SKILL.md`를 읽은 뒤에 쓴다. `<스킬 폴더>`는 이 문서가 있는 `references/`가 아니라 `SKILL.md`가 있는 폴더다. 원본 보존, 비공개·비밀정보, `src-` 링크, 링크 형식은 `SKILL.md`의 절대 규칙을 그대로 따른다.

`SKILL.md`의 볼트 경로 결정에서 쓸 폴더를 찾지 못했거나, 고른 폴더에 `CLAUDE.md` 라우터가 없거나, 사용자가 새 볼트를 요청했을 때만 한다. 각 단계는 사용자 확인 후 진행한다.

1. 볼트 경로를 묻는다. 클라우드 동기화 폴더(iCloud·Drive 등)보다 로컬 폴더를 권한다(동기화 충돌·민감정보 노출 방지).
2. 폴더가 없으면 만든다. 라우터가 없으면 `<스킬 폴더>/templates/CLAUDE.md`를 복사해 만들고, 영역(예: 업무·개인·공용)과 첫 주제 MOC를 사용자와 정해 표를 채운다. 영역 색인 파일(`work.md` 등)과 영역 폴더도 함께 만든다.
3. `AGENTS.md`가 없으면 `<스킬 폴더>/templates/AGENTS.md`를 복사한다(Codex용 한 줄 안내). `<볼트>/.claude/settings.json`이 없으면 `<스킬 폴더>/templates/claude-settings.json`을 복사한다(Claude Code가 비밀정보 파일을 읽지 못하고 `src-` 원본을 고치지 못하게 막는 규칙).
4. 원본을 그대로 두고 연결할 외부 폴더가 있으면 경로를 받아 `src-<이름>` 링크와 라우터 행을 만든다(운영체제별 명령은 `SKILL.md` 참고). 민감한 하위 경로는 라우터 비공개 줄에 적고, `SKILL.md` 절대 규칙대로 `settings.json`의 `permissions.deny`에도 추가한다.
5. 볼트 경로 한 줄을 설정 파일에 저장한다(폴더가 없으면 만든다). 설치할 때 `install.sh <볼트>`나 `install.ps1 <볼트>`로 저장했다면 건너뛴다.
6. 볼트를 git 저장소로 만들지 묻는다(색인 변경 이력·되돌리기용).

설정을 마치면 원래 요청으로 돌아가 `SKILL.md`의 절차(또는 전체 재색인)를 이어서 진행한다. 설정만 요청했으면 만든 파일과 저장한 볼트 경로를 보고하고 끝낸다.
