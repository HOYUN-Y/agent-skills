# 프로젝트 안내

[라우터](CLAUDE.md)

- 목적: 확인한 안내에 근거한 한 줄 설명.
- 정본: 안전한 코드·문서·설정으로 가는 상대 링크. 코드가 규칙표를 읽는 관계도 연결한다. 미확인 시 정본 후보로 표시한다.
- 상태: 기록일과 계획·로컬·QA·운영 구분. 현재 운영을 조회하지 않았다면 명시한다.
- 변경 근거: 기준본과 후속 변경 기록의 링크.
- 관련 작업: 날짜별 상세 안내 링크. 같은 해설을 다시 쓰지 않는다.
- 질문별 경로: 프로젝트에 맞는 질문과 근거 문서·규칙표 링크. 출처·갱신, 전처리·매핑, 구현·계약, 검증·배포, 운영 한계, 결정·후속 변경 중 필요한 축을 고른다.
- 질문별 확인 범위: 예) 출처·갱신 — 출처: [수집 기록](상대경로), 기록일 YYYY-MM-DD·본문 확인 / 갱신 주기: 미확인. 하위조건별로 근거·기록일·미확인을 나누고, 색인 설명만 재사용했으면 표시한다.
- 보류·한계: 비공개 자료는 링크하지 않는다. README가 보류돼도 안전한 프로젝트 진입점은 유지한다.
