# 정적 그래픽 기준

최종 이미지나 렌더링을 실제 게시 비율·사용 크기에서 확인한다. 원본 확대만으로 가독성을 판단하지 않는다. 공통 C2/C3와 중복되는 문제는 주 항목 하나에 기록한다.

| ID·항목 | 관찰 질문 | 7점 | 8점 | 9점 |
|---|---|---|---|---|
| G1 주목성·전달 거리 | 사용 거리와 노출 환경에서 핵심 정보를 식별할 수 있는가? 축소 시 초점이 유지되는가? | 원본에서는 보이지만 실제 게시 크기에서 핵심 정보가 묻힘 | 실제 사용 크기에서 핵심 메시지와 행동 정보를 식별함 | 축소·주변 시각 잡음 속에서도 정보 우선순위가 안정적임 |
| G2 이미지·합성 품질 | 해상도·크롭·경계·광원·원근·질감이 의도와 맞는가? 설명 그림이 정확한가? | 뭉개짐, 어색한 경계, 잘못된 크롭이 내용 이해를 방해함 | 최종 크기에서 자산이 선명하고 합성·도형 관계가 자연스러움 | 세부 질감과 크롭까지 통일된 표현을 강화함 |
| G3 출력·매체 적합성 | 크기·비율·안전 영역·파일 형식이 배포처 요구에 맞는가? 인쇄면 재단·해상도·색상 조건을 확인했는가? | 알려진 규격 불일치나 재단 시 필수 정보 손실 존재 | 제공된 출력 규격을 충족하고 필수 정보가 안전 영역 안에 있음 | 필요한 파생 크기에서도 구성과 출력 품질이 안정적임 |

## 증거와 보정

- 실제 사용 크기, 최종 파일, 필수 텍스트·출처·자산의 확인 범위를 기록한다. 출력 목적에 인쇄가 없으면 인쇄 검사는 제외한다.
- 인쇄소 규격을 모르면 임의의 DPI·재단 수치를 공식 규격처럼 사용하지 않는다. 관련 검증을 UNVERIFIED로 남긴다. 화면 확인으로 실제 인쇄 색상까지 보증하지 않는다.
- 행사 포스터: C1/G1에서 행사명·날짜·장소·신청 방법의 정확성과 발견성을 본다.
- 광고: C1/C5에서 제품·브랜드·구체적 가치가 드러나는지 본다. 근거 없는 광고 주장을 만들지 않는다.
- 인포그래픽: C1에서 수치·출처, C2에서 축·범례·단위·비교 관계를 본다. 왜곡된 축이나 틀린 수치는 장식 문제보다 우선한다.
