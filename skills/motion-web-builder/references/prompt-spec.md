# 전달 가능한 구현 프롬프트 작성

명세만 요청받았거나 구현 전에 상세 설계 산출물이 필요한 경우 사용한다. 아래 항목 중 실제 작업에 필요한 것만 포함한다. 예시 프롬프트의 길이나 8개 절을 맞추는 것이 목표가 아니다.

## 출력 형식

짧은 가정·미확정 사항 안내 다음에 복사해서 사용할 수 있는 완결된 프롬프트를 제공한다. 다른 도구가 대화를 알 필요가 없도록 브랜드·문구·자산·산출물을 본문에 적는다. 요청이 “프롬프트만”이면 안내도 프롬프트 안에 통합한다.

단, 필수 조건이 충돌하면 “프롬프트만” 요청이어도 충돌 설명과 필요한 확인 질문을 우선한다. 해결되지 않은 조건을 만족한다고 전제한 완성 프롬프트를 만들지 않는다.

영문 프롬프트를 요청받으면 구현 지시를 영문으로 쓰되 제품에 표시할 문구의 언어는 별도로 보존한다.

## 명세 항목

| 항목 | 반드시 구체화할 내용 |
|---|---|
| 목적과 산출물 | 사용자·핵심 메시지·주 행동, 페이지 범위, 파일/프레임워크 계약, 명시된 제외 범위 |
| 자산과 실행 조건 | 실제 URL/경로·용도·확인 상태, 폰트, 라이브러리, 외부 연결 허용 여부, 실패 대체 |
| 시각적 방향 | 분위기와 근거, 배경·본문·강조색, 서체 역할, 크기·행간, 간격·모서리·그림자 토큰 |
| 구조와 문구 | 영역 순서, 실제 텍스트, 버튼·메뉴·폼의 동작, DOM과 장식 미디어 관계 |
| 구도와 반응형 | 기준 화면, 콘텐츠·피사체의 초점, 폭/높이별 재배치, 안전 영역, 스크롤 정책 |
| 모션 명세 | 트리거, 대상, 변화, 시간/속도, easing, 반복 여부, 중단·복귀·감소 상태 |
| 유형별 상세 | 영상 크롭·정지 대체, 마키 반복 단위, 3D 모델·카메라·재질 등 필요한 유형만 |
| 확인 기준 | 기준 크기와 시간별 상태, 실제 입력, 루프 이음새, 오류·감소·모바일 동작 |

## 모션 표

다음 열을 사용하되 복잡하지 않은 경우 서술형으로 합쳐도 된다.

| 대상 | 트리거 | 시작 → 끝 | 시간·속도 | 지연·easing | 반복·재개 | 모바일·동작 감소 |
|---|---|---|---|---|---|---|
| 실제 선택한 요소 | load / pointer / hover / scroll / action | 속성과 값 | ms, s, px/s 등 단위 | 실제 값 | 횟수·정지 조건·복귀 상태 | 대체 상태 |

표의 값은 모두 채우거나 선택 조건을 분명히 쓴다. 모호한 “부드럽게”, “고급스럽게”만으로 모션을 정의하지 않는다. 주기를 기다려야 보이는 결과에는 검증 시점을 적는다.

## 정합성 점검

- **단일 파일**: 원격 자산을 허용하는지, 완전 오프라인인지 구분한다. 별도 `assets/fonts/*.woff2`가 필요하면 독립 파일 조건과 충돌하는지 확인한다.
- **소재 가용성**: 존재하지 않는 경로를 최종 프롬프트에 사용 가능한 파일로 적지 않는다. 예산·정확 재현이 걸린 누락 자산은 확인하고, 허용된 설계 선택은 구체적인 대안으로 채운다.
- **서체와 문구**: 정확한 재현이면 폰트 파일과 해당 언어 글리프를 확인한다. 새 브랜드라면 레퍼런스의 오탈자·고정 날짜·전화번호·허구 실적을 자동으로 옮기지 않는다.
- **배치와 동작**: 최종 transform과 레이아웃 transform, 이미지 크롭과 영상 크롭, 등장 종료와 반복 시작이 서로 맞는지 확인한다.
- **반응형**: 데스크톱 좌표만 상세하고 모바일은 “반응형으로”로 끝나는 명세를 만들지 않는다.
- **검증 근거**: 참조 스크린샷·실행 결과 없이 “픽셀 일치”, “완전 검증”, “60fps 보장”이라고 쓰지 않는다.
- **요구 충돌**: 필수 조건끼리 충돌하면 임의로 하나를 버리거나 완성 프롬프트로 포장하지 말고 해당 선택을 확인한다.

## 변주 시 연관 변경

| 변경 요청 | 함께 검토할 곳 |
|---|---|
| 강조색 | CTA·포커스·SVG·광원·재질·파티클·배경·수용 기준 |
| 브랜드·문구·언어 | 메타 정보·탐색·본문·접근성 이름·행 나눔·글리프·모바일 높이 |
| 미디어 교체 | 비율·해상도·밝기·피사체 위치·정지 대체·크롭·로딩 |
| 모션 강도 | 거리·시간·보간·반복·호버·대기 상태·동작 감소 |
| 캐릭터 교체 | 모델 구조·피벗·부품 좌표·재질·리깅·카메라·반응 영역 |
| 프레임워크 변경 | 기존 라우팅·자산 로드·생명주기·이벤트 및 자원 해제 |

바뀌지 않은 영역의 긴 설명을 반복할 필요는 없다. 다만 “전체 프롬프트”를 요청받으면 변경 사항을 통합한 독립 문서로 반환한다.
