# 내장 Mosaic 템플릿 사용

## 출처와 유지보수

`assets/translation-mosaic.html`은 이 저장소의 `insight-design-theme/references/theme.md`, `assets/web/base.css`, `assets/web/pixel.js`를 바탕으로 만든 번역 전용 템플릿이다. Navy/Slate/Gold 색, Pretendard 우선 글꼴, 원본 벡터 로고, 점 격자를 유지한다. 고정 높이 카드 템플릿 대신 긴 본문이 흐르는 구조다. 원본 테마를 고치지는 않는다. 향후 브랜드 변경 시 이 판본도 비교해 갱신한다.

테마가 내용을 바꾸지 않도록 원문의 절 순서·그림 위치·표 셀·참고문헌을 유지한다. 표지용 제목 줄 수에 맞추려고 논문 제목을 줄이지 않는다. 임시 소셜 핸들이나 홍보용 마무리는 넣지 않는다.

## 슬롯 채우기

출력 폴더에 템플릿을 복사하고 다음 슬롯을 **한 번에** 치환한다. 단순 순차 치환으로 삽입된 원문 속 슬롯 문자열까지 다시 바꾸지 않는다.

| 슬롯 | 값 |
|---|---|
| `{{DOCUMENT_TITLE}}` | 브라우저 제목, HTML 이스케이프한 텍스트 |
| `{{TITLE}}` | 한국어 제목, HTML 이스케이프한 텍스트 |
| `{{SOURCE_TITLE}}` | 원문 제목, HTML 이스케이프한 텍스트 |
| `{{METADATA_HTML}}` | 확인된 저자·버전·출처 링크·번역 범위 |
| `{{TOC_HTML}}` | 실제 절 ID에 연결된 목차 링크 |
| `{{CONTENT_HTML}}` | Markdown에서 생성한 본문 |

메타데이터와 본문을 만들 때도 텍스트를 이스케이프하고, URL은 허용된 링크 형식인지 확인한다. 원문의 HTML·스크립트·이벤트 속성을 실행 가능한 마크업으로 그대로 삽입하지 않는다. 본문에서 슬롯과 같은 문자열을 인용했다면 오류로 오인하지 않는다.

범용 Markdown 파서는 개별 문단·목록·표를 변환하는 데 사용한다. 파서가 원문과 `> [번역]` 문단을 자동으로 짝짓는다고 가정하지 말고, 문서 구조를 확인하며 `.pair > .original + .translation`으로 묶는다. 원문 자체의 인용과 번역 표지를 구분한다. 수정 후에는 Markdown에서 HTML 전체를 재생성하며, 출력 폴더에 사용한 변환 스크립트와 실행 명령을 남긴다. HTML만 부분 수정해 두 원본이 어긋나게 하지 않는다.

템플릿의 CSP는 외부 리소스와 스크립트 실행을 차단한다. 수식은 사전 렌더링하고 이미지·글꼴은 내장한다. CSP를 제거해 로딩 문제를 숨기지 않으며, 이스케이프와 실제 오프라인 검수는 별도로 수행한다.

본문은 아래 구조를 따른다. 원어가 영어가 아니면 해당 `lang` 값을 사용한다.

```html
<section id="abstract" aria-labelledby="abstract-heading">
  <h2 id="abstract-heading">초록 <span lang="en">Abstract</span></h2>
  <div class="pair" data-source="p.1, abstract, paragraph 1">
    <div class="original" lang="en"><p>Source paragraph.</p></div>
    <div class="translation" lang="ko"><p>번역 문단.</p></div>
  </div>
</section>
```

- 각 원문/번역 블록은 `original`/`translation` class로 구분한다. 표·목록은 항목/셀별로 대응시킨다. 한국어 전용이면 `original`을 제외한다.
- 역주는 `aside.translator-note`로 분리한다. 코드는 `pre > code`, 그림은 `figure > img + figcaption`, 표는 `table`과 `th`를 사용한다. 넓은 표만 `.table-scroll`로 감싼다.
- 숫자·단위·모델명처럼 쪼개지면 오독할 셀/구간에는 `.nowrap`을 사용한다. 설명 문장까지 전체 표에 줄바꿈 금지를 걸지 않는다.
- 그림을 data URI로 내장한다. 도식 내부 글자는 이미지만 확대해도 읽을 수 있어야 한다. 표·캡션·본문을 스크린샷 한 장으로 대체하지 않는다.
- 템플릿은 정적 HTML이며 Markdown·LaTeX 변환기는 아니다. 작업 환경에 있는 파서를 사용하고, 수식은 검증된 로컬 렌더러로 HTML/MathML 또는 SVG로 변환한다. SVG 수식에는 원식/설명에 해당하는 접근 가능한 텍스트를 제공한다. CDN만 연결한 채 오프라인 지원이라고 보고하지 않는다.

## 글꼴과 독립 파일

템플릿은 Pretendard와 코드용 DejaVu Sans Mono를 우선하고 시스템 한글 글꼴로 대체할 수 있다. **정확한 브랜드 글꼴은 템플릿에 포함돼 있지 않다.** 기존 테마의 검증된 정적 글꼴이 있으면 필요한 굵기만 `@font-face`의 data URI로 넣고 라이선스 고지를 HTML에 보존한다. 테마 스킬이 설치돼 있으면 그 스킬의 글꼴 준비 절차를 재사용할 수 있다. 시스템 설치는 필요 없다.

글꼴이 없으면 대체 글꼴로 진행한 사실을 보고한다. 네트워크 글꼴 링크나 존재하지 않는 파일 경로를 넣지 않는다. 출력 HTML 하나를 다른 폴더로 복사하고 외부 요청을 막아 이미지·수식·레이아웃을 확인한다.

이 저장소의 기존 테마에도 글꼴 바이너리는 기본 포함되지 않는다. 정확한 브랜드 글꼴이 필요하면 `insight-design-theme/scripts/fetch_fonts.py`의 검증된 다운로드 절차(인터넷 필요)를 사용해 받은 파일을 내장하거나, 사용자가 제공한 적법한 글꼴을 사용한다. 코드용 글꼴이 없을 때는 Menlo·Consolas·시스템 고정폭 글꼴을 사용하며, 한글만 대체 글꼴을 사용한다.

## PDF와 검수

같은 HTML을 사용 가능한 브라우저의 인쇄 기능으로 A4 PDF로 출력한다. 글꼴과 모든 이미지가 로드되고 수식 렌더링이 끝난 뒤 인쇄한다. 배경 인쇄를 켜고 브라우저 기본 URL/날짜 머리말은 끈다.

번역 본문은 화면 16px, 인쇄 11.5pt를 기본으로 유지한다. 원문보다 무조건 2pt 작게 만들지 않는다. 사용자가 크기 차이를 요구하면 원문을 키우고 한국어 가독성은 유지한다. 표가 넘치면 분할·가로 페이지 등으로 해결하고 본문 전체를 축소하지 않는다.

긴 문단은 페이지 사이에서 흐르게 하고, 짧은 원문/번역 쌍만 필요에 따라 `pair keep-together`로 묶는다. 모든 쌍에 분할 금지를 걸어 큰 공백을 만들지 않는다. 넓은 표·수식은 `.landscape` 블록으로 감싸 가로 A4 페이지를 사용한다. 가로 페이지에서도 넘치면 표를 열 묶음별로 나누고 행 식별자를 반복하거나 수식을 의미 단위로 나눈다. CSS의 `overflow:visible`만으로 인쇄 잘림이 해결됐다고 판단하지 않는다. 읽을 수 있는 배치를 만들지 못하면 해당 PDF 검수 실패를 기록하고 해결 전에는 완료로 보고하지 않는다.

표 머리 반복, 그림/캡션 분리, 긴 코드 줄, 수식 잘림과 목차 링크를 실제 출력에서 확인한다. 검증기록에는 글꼴 대체·외부 의존성·미검수 페이지와 PDF 북마크 제공 여부를 명시한다. HTML 목차가 PDF 북마크를 자동 생성한다고 가정하지 않는다.
