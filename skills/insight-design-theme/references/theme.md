# Artificial Insight 디자인 테마 정의

이 문서는 테마의 기준이다. 스크립트 없이 다른 매체(웹 페이지, 썸네일, 배너)에 손으로 적용할 때도 이 문서를 따른다. 실제 값은 `assets/web/base.css`(색·글꼴 변수)와 템플릿(`assets/web/mosaic.html`, `terminal.html`, `assets/ppt/deck.js`)에 있다. 값을 바꿀 때는 이 문서와 그 파일들을 함께 고친다.

시각 견본: `assets/examples/showcase.json`을 빌드하면 색·글꼴·블록이 한 문서에 나온다.

이 저장소의 번역 전용 판본은 `skills/translating-report/assets/translation-mosaic.html`이다. 브랜드 색·글꼴·로고를 변경하면 해당 템플릿도 비교해 갱신한다. 번역 스킬은 이 템플릿을 내장하므로 별도 설치본에서는 원본 테마 변경이 자동 반영되지 않는다.

## 1. 핵심 개념

**흩어진 픽셀이 모여 하나의 면과 로고가 된다.** 정보가 앞에서 뒤로 쌓이는 과정(단계, 진행, 완성)을 픽셀의 밀도와 조립으로 보여 준다. 바탕은 네이비와 슬레이트, 강조는 로고에서 온 금색 하나다.

| 스타일 | 인상 | 어울리는 곳 |
|---|---|---|
| **mosaic** | 밝은 슬레이트 점 격자 지면. 아래로 갈수록 디더링이 짙어져 네이비 면이 된다. 에디토리얼, 인쇄물 | 내려받아 읽는 PDF, 인쇄, 밝은 발표장 |
| **terminal** | 전면 다크 네이비. 한글 픽셀 제목, `$` 명령줄, 터미널 창, 줄 단위로 밀려 들어오는 로고 | 휴대폰 화면, 인스타 카드, 어두운 화면 공유 |

한 문서 안에서 두 스타일을 섞지 않는다.

## 2. 로고

- 구성: 아이보리 **A**(#F6F1E7) + 금색 **i** 기둥과 눈(#FFB52E), 네이비 바탕(#162033). 원본 좌표는 `assets/web/pixel.js`의 `LOGO_BOX`, `IVORY`, `GOLD_*`.
- 쓰는 형태
  - **벡터 타일**(`PX.logoTile`): 머리줄의 작은 로고. 네이비 정사각형 안에 원본 그대로.
  - **픽셀 로고**(`PX.logoGrid`): 칸으로 래스터화한 로고. Mosaic 표지·마무리의 디더 면 위, Terminal 마무리.
  - **줄 단위 조립 로고**(Terminal 표지): 줄마다 일부 칸이 왼쪽에서 밀려 들어오는 중. 완성형은 마무리에 쓴다.
- 픽셀 로고는 가로 22칸 이상으로 그린다. 그보다 작으면 눈이 뭉개진다.
- i의 눈은 어느 크기에서나 좌우·상하 대칭이고, i 기둥의 가장 넓은 윗부분과 같은 세로축에 놓인다. 칸이 눈 테두리보다 큰 크기(가로 33칸 이하)에서는 손으로 찍은 눈 도트를 쓴다. 기둥 축이 칸 중심이면 7칸, 칸 경계면 8칸이다. 그보다 촘촘하면 래스터화한 눈을 축 기준으로 접어 대칭을 맞춘다(`pixel.js` `logoGrid`).
- 색을 바꾸거나, 늘이거나, 사진·복잡한 배경 위에 올리지 않는다. 밝은 지면에서는 네이비 타일 안에 넣는다.

## 4. 글꼴과 크기

| 역할 | 글꼴 | 이유 |
|---|---|---|
| 본문·제목 | Pretendard(정적 굵기 400~900) | 가변 글꼴은 Chrome PDF에서 Type3로 들어가 복사 순서가 섞인다 |
| 코드·프롬프트 | DejaVu Sans Mono 복사 보정본(한글은 Pretendard) | 기호가 붙어 있어도(`- .env`, 밑줄 등) PDF 복사 줄이 끊기지 않게 경계 상자 값만 보정, 모양은 원본과 같다 |
| 라벨·머리줄·경로 | JetBrains Mono | 숫자·경로가 또렷하다 |
| Terminal 제목 | Neo둥근모 Pro(웹), Galmuri11(PPT) | Neo둥근모 Pro는 PowerPoint에서 보이지 않는다(UPM 16) |
| 영문 픽셀 라벨 | Silkscreen | STEP, 숫자 같은 짧은 영문만. 한글 문장에 쓰지 않는다 |

크기(본문 기준은 휴대폰에서 읽히는지):

| | A4 PDF | 4:5 카드 | 16:9 PPT |
|---|---|---|---|
| 표지 제목 | 44pt(Terminal 34pt) | 27pt(22pt) | 40pt(3줄이면 28pt) |
| 섹션 제목 | 24pt | 17pt | 32pt |
| 본문 | 11.5pt | 10.5pt | 17pt |
| 코드 | 11pt | 9.5pt | 15pt |
| 라벨 | 8pt | 7pt | 10~12pt |

4:5 카드는 휴대폰 화면 폭에서 약 1.15배로 보이므로 10.5pt 본문이 약 12pt로 읽힌다. A4는 휴대폰에서 약 0.65배라 확대해 읽는다(그래서 인스타 게시물 이미지는 카드 형식을 쓴다).

자간: 큰 한글 제목은 -0.02~-0.035em. 본문은 기본. `word-break: keep-all`로 한글 낱말 중간에서 줄을 바꾸지 않는다(PPT는 글자 언어 ko-KR).

## 5. 지면

| 형식 | 크기 | 좌우 여백 | 머리줄 / 본문 시작 / 본문 끝 / 바닥줄 |
|---|---|---|---|
| A4 | 210×297mm | 16mm | 13 / 29 / 아래 20 / 아래 10mm |
| 카드 | 120×150mm(4:5, PNG 1080×1350) | 9mm | 7 / 17 / 아래 14 / 아래 6mm |
| PPT | 13.33×7.5in | 0.75in | 0.38 / 1.95 / 6.8 / 7.0in |

- 머리줄: Mosaic는 로고 타일 + 브랜드 이름 / 시리즈·호수, Terminal은 `브랜드-슬러그 ~/시리즈/호수` / 쪽 번호.
- 바닥줄: 핸들 / 쪽 번호. 표지와 마무리 디더 면에는 바닥줄을 두지 않는다.
- Mosaic 지면 점 격자: 12px 간격, 지름 약 1.6px, #C9D2DE.
- Terminal 아래 띠: 바닥 쪽으로 짙어지는 디더 띠(Navy 900).
- 섹션 제목: Mosaic는 굵은 제목 + 오른쪽 고정폭 태그 + 아래 2px 네이비 선. Terminal은 금색 `$` + 픽셀 제목, 아래 `// 태그`.
- 카드 형식은 섹션마다 새 장에서 시작한다(한 장 = 한 주제). 앞 장이 절반 넘게 비어 있으면 이어 써서 거의 빈 카드를 만들지 않는다. A4는 섹션이 이어 흐른다.

## 6. 픽셀 모티프

픽셀 그래픽은 장식이 아니라 **순서와 완성도**를 나타낸다.

| 모티프 | 뜻 | 어디에 |
|---|---|---|
| 디더 면(밀도 0→1 후 네이비 면) | 흩어진 것이 모여 하나가 됨 | Mosaic 표지·마무리 |
| 6×6 미터(베이어 순서로 채움, 다 차면 금색 한 칸) | k/N 진행 | Mosaic 단계 카드, 큰 숫자 비율 |
| 진행 칸 줄 | k/N 진행 | Terminal 단계, 큰 숫자 비율 |
| 칸 막대(한 줄 10칸, 같은 블록은 같은 틀, 아래에 `1칸 = …`) | 같은 단위로 잰 양 비교 | 큰 숫자 `cells`(Mosaic 네이비, Terminal 금색) |
| 5×7 픽셀 숫자 | 호수, 요점 번호 | Mosaic 표지, 요점 |
| 줄 단위 조립 로고 | 만드는 중 → 완성 | Terminal 표지(조립 중), 마무리(완성) |
| 해설 번호 배지 | 코드 줄과 해설 연결 | 코드 블록 |

- 그래픽은 SVG 사각형(PDF)이나 PNG(PPT)다. 같은 시드면 같은 배치가 나온다.
- 칸 크기는 지면 폭을 나누어떨어지게 잡는다(가장자리 반쪽 칸 방지).
- 번호·배지·장식은 그림이고, 읽고 복사할 글자는 글자로 둔다.

## 7. 블록 모양

| 블록 | Mosaic | Terminal |
|---|---|---|
| text | 회색 본문 | 슬레이트 본문 |
| list | 네이비 사각 점, 번호면 고정폭 `01` | 금색 `>` 또는 `01` |
| callout | 네이비 면 + 아이보리 글자 + 금색 픽셀 표시 | 금색 테두리 상자 + `// 라벨` + 픽셀 제목 |
| quote | 픽셀 따옴표 + 굵은 네이비 문장 | 금색 세로선 + 픽셀 글꼴 문장 |
| stats | 흰 카드, 큰 숫자(Pretendard 900, 한 줄), 비율이면 미터, 칸 수면 네이비 칸 막대 | 네이비 카드, Silkscreen 금색 숫자(한 줄), 비율이면 진행 칸, 칸 수면 금색 칸 막대 |
| steps | 흰 카드 2열(A4), 미터, 라벨 줄은 점선 위 | 타임라인 + 네이비 카드, 진행 칸 |
| points | 픽셀 숫자 + 제목 + 설명, 가는 구분선 | `[1]` + 픽셀 제목 카드 |
| table | 고정폭 머리, 2px 네이비 선, 흰 줄무늬 | Navy 950 머리 + 금색 고정폭, 네이비 줄무늬 |
| code | 흰 상자 + 왼쪽 6px 네이비 막대, 빈칸 금색 면 | 터미널 창(점 3개, 제목줄), 빈칸 금색 테두리 |

코드 줄이 화면에서 줄바꿈되면 다음 줄은 앞 공백과 목록 기호(`-`, `*`, `+`, `1.`) 길이만큼 들여 쓴다(내어쓰기, 최대 12칸). 글자는 바꾸지 않고 배치만 바꾸므로 복사 텍스트는 같다. 큰 숫자 값은 줄바꿈하지 않고, 길면 같은 블록의 값을 함께 작게 그린다.

빈칸 `[ ]`, 인라인 코드, `## 소제목`, 생략 줄(`··· 생략:`), 해설 번호는 두 스타일 모두 같은 규칙으로 표시한다(`assets/web/pixel.js` `promptLines`).

## 8. 다른 매체에 적용할 때

웹 페이지, 썸네일, X 헤더처럼 템플릿이 없는 매체:

1. 스타일 하나를 고른다(밝은 매체 mosaic, 어두운 매체 terminal).
2. `assets/web/base.css`의 `:root` 변수(색·글꼴)를 그대로 가져다 쓴다. 글꼴 파일은 `fetch_fonts.py`로 받은 것을 쓴다.
3. 화면 하나에 픽셀 모티프는 하나만(디더 면 또는 조립 로고 또는 미터). 로고는 2절 규칙대로.
4. 금색은 한 곳. 나머지는 네이비·슬레이트·아이보리로만.
5. 픽셀 그래픽이 필요하면 `assets/web/pixel.js`의 함수(`logoGrid`, `digits`, `bayer`, `svg`)를 쓴다.
6. 결과를 견본(`showcase` 빌드)과 나란히 놓고 색·글꼴·여백이 같은지 본다.

## 9. 하지 말 것

- 금색 넓은 면, 그라데이션, 그림자, 둥근 모서리(모든 상자는 직각).
- 한 문서에 두 스타일 섞기, 테마 밖의 색 추가.
- 복사해 쓸 글자(코드·프롬프트·본문)를 그림으로 만들기.
- 픽셀 글꼴로 긴 한글 문장 쓰기(제목·짧은 문구만).
- 로고 변형, 사진 위 로고.
