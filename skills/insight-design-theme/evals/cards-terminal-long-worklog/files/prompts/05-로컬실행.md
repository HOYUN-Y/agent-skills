# 05. 로컬 실행 프롬프트

> 사용법: 04 검수에서 '높음' 문제가 없을 때 실행한다.

---

대시보드를 내 노트북에서만 열리게 실행 환경을 만들어라. 인터넷에 공개하지 않는다.

## 작업 위치
- 작업 폴더: /Users/jiwoo/Projects/morning-dashboard
- 이 폴더 밖의 파일은 고치지 않는다. 필요하면 먼저 물어본다.

## 만들 것
1. 실행 스크립트 run.sh
   - 로컬 서버를 127.0.0.1에서만 연다. 0.0.0.0으로 열지 않는다.
   - 포트는 [예: 4173]. 이미 쓰이고 있으면 다른 포트를 고르지 말고 멈춰서 알린다.
   - 실행하면 브라우저를 자동으로 연다.
2. 아침 자동 실행
   - 로그인할 때 run.sh가 실행되게 한다. 방법은 [launchd / 로그인 항목 중 하나].
   - 설정 파일을 만들기 전에 어떤 파일을 어디에 만드는지 보여주고 승인을 받는다.
3. 중지 스크립트 stop.sh
   - 서버만 끄고 데이터 파일은 건드리지 않는다.

## 지켜야 할 것
- 새 패키지를 설치해야 하면 이름과 이유를 말하고 승인을 받는다.
- .ics 파일과 notes/todo.md는 읽기만 한다. 쓰지 않는다.
- 비밀번호나 토큰을 파일에 적지 않는다.
- 같은 문제로 두 번 실패하면 멈추고 시도한 내용을 정리해서 보고한다.
- 문제가 생기면 jiwoo.kim@example.com 으로 보낼 보고 메일 초안을 써라.

## 확인
1. run.sh 실행 → 브라우저에서 대시보드가 열리는지
2. 다른 기기에서 같은 주소로 접속이 안 되는지
3. stop.sh 실행 → 서버가 꺼지는지
4. 노트북 재시작 후 자동 실행되는지(직접 재시작은 하지 말고 설정만 확인)
