# 개인 아침 대시보드 만들기 작업 기록

도구: Claude Code. 6단계로 나눠 프롬프트를 보냈다. 단계별 프롬프트는 prompts/ 폴더에 있다.

1. 요구 정리: 무엇을 보여줄지 나에게 질문만 하고 코드는 쓰지 않게 했다. 결과는 화면 목록 초안.
2. 데이터 연결: 캘린더(.ics 파일)와 할 일 메모(마크다운)를 읽는 부분만 만들게 했다. 외부 API 연결은 하지 않았다.
3. 화면 구현: 1단계 화면 목록대로 만들게 했다. 색은 다크 모드 하나만.
4. 검수: 구현한 세션과 다른 새 세션에서 실행했다. 고치지 말고 문제 목록만 내게 했다.
5. 로컬 실행: 내 노트북에서만 열리게 실행 스크립트까지 만들게 했다. 인터넷 공개 배포는 하지 않았다(프롬프트가 길다: prompts/05-로컬실행.md).
6. 정리: 사용법 README와 다음에 쓸 프롬프트 템플릿을 저장하게 했다.

결과: 1~5단계는 끝냈다. 6단계 README는 초안만 있고 아직 다듬지 않았다. 대시보드는 지금 매일 아침 내 노트북에서만 쓰고 있다.
