# 작업 메모 (2026-11-05)

- 같은 이미지 생성 도구로 01과 02를 각각 3번씩 실행해 비교했다.
- 01: 3번 모두 날짜·장소가 없었다. 1번은 영어 제목이 들어갔다.
- 02: 3번 중 2번은 정보가 모두 들어갔다. 1번은 장소 글자가 깨졌다('망원동'이 '망원둥').
- 03: 수정 한 번으로 날짜 가독성은 해결. 제목 한 줄은 두 번째 수정 요청에서야 됐다.
- 최종 포스터는 실제 행사에 쓰지 않았다(가상의 모임으로 실험).
- 배운 점: 꼭 들어갈 정보와 넣지 말 것을 따로 적으니 결과가 안정됐다. 수정은 한 번에 세 가지 이하로 보낸다.
