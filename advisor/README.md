# Advisor — 기술 자문 에이전트

계획을 확정하기 전, 같은 오류가 반복될 때, 완료를 선언하기 전에 현재 판단이 근거와 맞는지 자문합니다. 구현을 대신하는 작업자가 아닌 기술 리드 역할입니다. 사용자가 요청할 때만 실행하며 자동 호출 훅은 설치하지 않습니다. 설명에 적은 호출 원칙이 자동 호출을 기술적으로 차단하는 것은 아닙니다.

공통 지침은 [advisor-spec.md](advisor-spec.md), 도구별 모델·권한 설정은 [adapters/](adapters/)에 있습니다. code-reviewer와 별도 이름으로 등록하되 기존 설치·충돌 보호 로직을 공유합니다.

## 모델과 권한

- Codex: `model = "gpt-6-astra"`.
- Claude Code: `model: fable`. Fable 계열의 별칭이며 현재 공식 문서 기준 Fable 5.2를 가리킵니다. 별칭이므로 향후 대상이 바뀔 수 있습니다. Fable 5.2는 Claude Code 2.1.321 이상이 필요합니다.
- 추론 강도는 별도로 고정하지 않습니다. 클라이언트의 상속·기본 설정을 따릅니다. 높은 모델 사용은 더 높은 비용·대기 시간을 수반할 수 있습니다.
- 지정 모델을 못 쓰면 중단하고 보고합니다. 다른 모델의 결과를 자문 완료로 인정하지 않습니다. 부모는 실제 `advisor` 호출·지침 버전·실행 모델을 실행 기록으로 확인해야 합니다. 실제 모델을 확인하지 못했다면 확인 불가로 남깁니다.

모델 설정과 실제 강제 여부는 다릅니다. Claude는 호출 인자·강제 모델 설정·허용 목록·fallback 설정 등에 따라 모델을 바꿀 수 있습니다. 이 도구는 전역 설정이나 훅을 바꾸지 않으며 대체를 운영체제 수준에서 막지 않습니다. 모델이 바뀌었다는 경고·실행 기록이 있으면 자문 성공으로 처리하지 말고 사용자에게 알립니다.

Claude는 Read·Grep·Glob만 제공하고 plan 모드를 지정합니다. Codex는 부모 권한·도구를 상속하므로 읽기 전용 샌드박스 등 실제 제한은 부모에서 설정합니다. 공통 지침은 파일 수정·셸 실행·테스트·외부 조회·추가 에이전트 호출을 금지합니다. 읽기 도구가 없으면 셸로 우회하지 않고 전달된 근거만 사용하며 직접 확인하지 못했다고 보고합니다. 필요한 실행 검증은 부모에게 제안합니다.

근거(2026-11-13 확인): [OpenAI 공식 서브에이전트 문서](https://learn.chatgpt.com/docs/agent-configuration/subagents), [Claude 서브에이전트 모델 선택](https://code.claude.com/docs/en/sub-agents#choose-a-model), [Fable 모델 설정](https://code.claude.com/docs/en/model-config#work-with-fable).

## 프로젝트에 설치

저장소 루트에서 Node.js 20 이상으로 실행합니다. TOML 파싱 테스트에는 Python 3.11 이상이 필요하며 새 의존성은 없습니다.

```sh
node reviewer/scripts/build-agents.mjs --project "/path/to/project" --agent advisor
node reviewer/scripts/build-agents.mjs --project "/path/to/project" --agent advisor --check
```

생성 파일은 `<project>/.claude/agents/advisor.md`, `<project>/.codex/agents/advisor.toml`입니다. 두 파일에 동일한 공통 지침과 SHA-256 버전을 넣습니다. 기본 리뷰어 설치 명령과 파일에는 영향을 주지 않습니다.

기존 파일이 같으면 쓰지 않고 다르면 양쪽 생성 전에 중단합니다. 설치 경로의 심볼릭 링크는 거부하며 자동 덮어쓰기는 하지 않습니다. 쓰기 도중 권한 오류·중단이 생기면 일부 파일만 생길 수 있습니다. 새 임시 폴더에 생성해 차이를 검토하고 복구합니다. 설치 후 해당 프로젝트에서 새 세션을 시작해 등록을 확인합니다. 전역 설치는 지원하지 않습니다.

## 요청 예시

부모는 목표·요구사항, 현재 근거, 접근 또는 시도, 결정할 질문과 읽어도 되는 경로·제외 경로를 전달합니다. 근거는 비밀값을 제거한 원문인지 부모의 요약인지 구분합니다.

계획 자문:

```text
advisor를 호출해 계획을 자문해 주세요.
목표: CSV 내보내기 추가. 기존 서비스 함수를 재사용하고 새 의존성은 넣지 않습니다.
근거: docs/export.md의 요구사항, src/export/의 현재 구현. 그 경로만 읽어도 됩니다.
접근: API 응답을 전부 메모리에 모아 CSV로 변환하려 합니다.
질문: 데이터 규모를 고려하면 적절한가요? 더 단순한 방법과 놓친 위험은 무엇인가요?
```

원인 분석 자문:

```text
advisor를 호출해 반복 오류의 원인 추론을 자문해 주세요.
목표: 업로드가 성공해야 합니다. 아래 로그는 비밀값을 제거한 원문입니다.
근거: <기대 결과·실제 오류·실행 환경·로그>
시도: A <변경과 결과>, B <변경과 결과> 모두 실패했습니다.
질문: 잘못 가정한 것은 무엇이고 다음 어떤 관찰로 가설을 구분해야 하나요?
코드는 직접 읽지 말고 전달된 근거로 판단해 주세요.
```

완료 판단 자문:

```text
advisor를 호출해 완료 판단을 자문해 주세요.
요구사항: <요구사항과 완료 조건>
구현: <변경 요약과 관련 경로>
검증: <실행한 명령·결과·미실행 항목. 원문인지 요약인지 표시>
질문: 완료 근거가 충분한가요? 완료 전에 필수인 확인과 선택적 개선을 구분해 주세요.
전체 독립 코드 리뷰나 명령 실행은 요청하지 않습니다.
```

응답은 판단 → 근거 → 놓친 위험·대안과 비용 → 다음 확인 순서로 받습니다. 실제로 읽은 자료와 전달된 설명, 추론·미확인을 구분합니다. 완료 자문은 사용자 승인·배포 허가나 전체 코드 품질 보증을 대신하지 않습니다.

## 검증

저장소 루트의 공통 생성기 테스트로 양쪽 지침 일치·TOML 파싱·모델 설정·재실행·충돌 보호·CLI 선택·리뷰어와의 공존을 확인합니다.

```sh
node reviewer/tests/build-agents.mjs
python3 -I reviewer/tests/fixtures.py
```

2026-11-13에 위 두 명령과 `python3 tests/check_portability.py`, `git diff --check`를 Node.js 26.7.0·Python 3.14.6에서 실행해 통과했습니다.

실제 모델 호출·자문 품질은 이 로컬 검사와 다릅니다. 이번 advisor의 실제 호출은 미검증입니다. 별도 승인된 합성 예제로 계획(더 단순한 대안과 비용), 반복 오류(가설을 구분할 다음 확인), 완료(충족·미충족 근거 구분), 정보 부족(조건부 판단·필수 질문)을 확인해야 합니다. 각 실행은 실제 전용 종류·모델·지침 버전, 파일 무변경·금지 도구 미사용도 원본 실행 기록으로 대조합니다. 코드와 지침의 외부 모델 전송은 사용자 승인 후에만 수행합니다.
